# How to use

## NOTE
This project is **UNDER-DEVELOPMENT** and is not finished. The current state of it is a framework to integrate and build further scripts for GeoFS with a unified UI system. 

## Current Support
In a clean, simple and elegant user interface which does not clutter your page and is easily hideable. There are some great features availiable.

"Lookout"
- Headtracking for immersion in cockpit cam.
- Fully locally run, webcam based. No extra equipment (ensure a well lit and clear image)

"Benevolance"
- New Dark theme
- Remove Foos from map
- Remove Foos from in-game (nametags AND models)
- Map Style Customisation 
- Chat repositioned for visibility

"Chat Fix"
- wysiwyg, fixes the chat. 
- Re-implements the "t" keybind to send chat messages (also customisable!)

"Freelook"
- Quickly and easily orbit your camera

"Info Panels" toggle-able panels
- Missile list
- FPS display
- Flight characteristics display

"Waypoint Visualisation"
- Fully customisable waypoint display
- See your flight plan, in-game instead of just in nav.

"OverG Shaders"
- Customisable blackout and redout
- Can be disabled and configured for realism (AGSM training, G-suit)

## Plan
The vision is an integrated, seamless experience for GeoFS with a modular and scalable design. I have a lot planned and the current structure means it is very easy to extend.

- Customisable chat filters (remove MRP, show only MRP, highlight vs remove, extra information per message)
- Customisable Smoke (colours, size, location, toggle keybinds etc) 
- Customisable map filters
- Friend lists, favourite locations etc
- MSFS Style landing stats
- Higher quality flight recordings
- Situational Awareness
> - Extending ability to be able to see more information and stay aware of your surroundings
> - Flight path vectoras
> - Target disgnator boxes
- Integration with other scripts, modified and improved. Integrated with the UI and extended customisability/
> - Modifiedd Autothrottle Integration + keybinds for mouseless control
> - Slew mode integration
> - Aircraft Fuel
... and so much more to create the best one stop shop for every GeoFS player, regardless of what they are doing.
