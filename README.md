# How to use

## NOTE
This project is **UNDER-DEVELOPMENT** and is not even close to finished. The current state of it is a framework to integrate and build further scripts for GeoFS with a unified UI system. 

## Current Support
In a clean, simple and elegant user interface which does not clutter your page and is easily hideable. There are some great features availiable.
"Advanced Labels"
- Improve in-game nametags
- Remove Foos from in-game
"Lookout"
- Headtracking for immersion in cockpit cam.
- Fully locally run, webcam based. No extra equipment (ensure a well lit and clear image)
"Benevolance"
- New Dark theme
- Remove Foos from map
- Map Style Customisation 
- Chat repositioned for visibility in transparent UI
"Chat Fix"
- wysiwyg, fixes the chat. 
- Re-implements the "t" keybind to send chat messages (also customisable!)
"Freelook"
- Quickly and easily orbit your camera
"Info Panels" All panels are toggle-able with a single click on each
- Missile list
- FPS display
- Flight characteristics display
